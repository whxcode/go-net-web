## POST 给该群添加群成员

> Body 请求参数

```json
{
  "memberIDs": [
    0
  ]
}
```

|---|---|---|---|---|

## PUT 修改当前用户在该群的信息(如：是否静音、是否加密、是否退群等)

PUT /groups/{id}/putMember

注意： 所属群主无法修改 Role、Status 状态

> Body 请求参数

```json
{
  "createdAt": "string",
  "groupId": 0,
  "id": 0,
  "isMuted": 0,
  "isNotifyDisabled": 0,
  "joinedAt": "string",
  "role": 0,
  "status": 0,
  "updatedAt": "string",
  "userId": 0
```
