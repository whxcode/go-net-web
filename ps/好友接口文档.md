## GET 获取好友列表

## POST 发起好友申请

POST /friends/request

好友表没有关系则新增一条记录 status = 0
好友表中已经存在；且 status != 1 或 != 0时；则重新更新 status = 0 和 remark(如果有传递)
好友表中已经存在；且 status == 1 或 = 0时；不会有任何变化；返回成功

> Body 请求参数

```json
{
  "friendID": 0,
  "remark": "string"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|token|header|string| 否 |必填|
|body|body|[controller.RequestResponse](#schemacontroller.requestresponse)| 是 |none|

> 返回示例

> 200 Response

```
{"code":0,"data":{"friendID":0,"remark":"string"},"message":"string"}
```

|状态码|状态码含义|说明|数据模型|

|500|[Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1)|服务器错误|[utils.KResponse](#schemautils.kresponse)|

## PUT 修改好友申请状态,可用于 同意(1),拒绝(2)、删除(3)

PUT /friends/{id}

如果将好友移除；同时也会移除对方的好友关系

> Body 请求参数

```json
{
  "status": 0
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|id|path|integer| 是 |修改好友申请状态;好友列表（表的 ID）|
|token|header|string| 否 |必填|
|body|body|[controller.PutRequesetRequestResponse](#schemacontroller.putrequesetrequestresponse)| 是 |none|

> 返回示例

> 200 Response

```
{"code":0,"data":{"status":0},"message":"string"}
```
