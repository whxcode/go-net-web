## POST 根据 hash 获取文件的 url 地址

POST /file/getfile

此接口生成的 url 地址；含有时效性；不建议作为长时间显示。

> Body 请求参数

```json
{
  "files": [
    "string"
  ]
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|token|header|string| 否 |必填|
|body|body|[controller.GetFileRequest](#schemacontroller.getfilerequest)| 是 |none|

> 返回示例

> 200 Response

```
{"code":0,"data":[{"hash":"string","url":"string"}],"message":"string"}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|成功|Inline|
|500|[Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1)|服务器错误|[utils.KResponse](#schemautils.kresponse)|

### 返回数据结构

状态码 **500**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|false|none||none|
|» data|any|false|none||none|
|» message|string|false|none||none|

## GET 根据 url 地址；下载文件;

GET /file/getfile/{hash}

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|hash|path|string| 是 |哈希地址|
|expred|query|string| 是 |过期时间|
|signature|query|string| 是 |签名|

> 200 Response

## GET 根据 hash 直接返回文件

GET /file/{hash}

注意该接口没有做任何权限验证；慎用；请使用 GetFile 接口获取带有时效性的 url 地址。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|hash|path|string| 是 |哈希地址|
|token|header|string| 否 |必填|

> 返回示例

> 200 Response

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|文件二进制数据|Inline|
|404|[Not Found](https://tools.ietf.org/html/rfc7231#section-6.5.4)|文件不存在|[utils.KResponse](#schemautils.kresponse)|

### 返回数据结构

状态码 **404**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|false|none||none|
|» data|any|false|none||none|
|» message|string|false|none||none|
