## GET 获取与好友的历史记录

GET /messages/firend/{friendID}

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|friendID|path|string| 是 |none|
|limit|query|integer| 否 |限制条数|
|offset|query|integer| 否 |偏移量|
|token|header|string| 否 |必填|

> 返回示例

> 200 Response

```
{"code":0,"data":{"data":[{"createdAt":"string","elements":[null],"id":0,"receiverId":0,"senderId":0,"status":0,"type":null}],"size":0,"total":0},"message":"string"}
```

|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|成功|Inline|
